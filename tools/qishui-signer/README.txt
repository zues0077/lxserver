汽水音乐 签名器（Windows 侧）
=================================

用途
----
让 NAS 上的 LX 能播汽水的**整曲/无损**。签名必须由官方客户端自带的
安全组件生成，所以需要一台装着「汽水音乐」客户端的 Windows 电脑在旁边。

怎么用（第一次只要两步）
------------------------
1. 双击 start-signer.bat
   窗口里会按提示问两件事：
     · LX 服务器地址（例：http://192.168.1.120:8027）
     · 后台管理员密码
   填完就会自动登记到 LX，并显示「✅ 已自动登记」。
   （下次双击不再问，直接自动登记）

2. 打开 LX 后台 →「平台账号」→ 点汽水音乐那一行的「填写 Cookie」
   （需要 SVIP 才有版权曲整曲）

如果显示「⚠️ 自动登记失败」，窗口里会打印一行地址，
复制它到 LX 后台「平台账号 → 汽水签名器」输入框，点「保存并测试」即可。

换服务器 / 重填
---------------
- 直接删掉本文件夹里的 signer-config.json，再次双击就会重新问；
- 或命令行：node signer.js --setup
- 也可以临时指定：node signer.js --pair http://新地址:8027 --password 密码

注意
----
signer-config.json 里存了服务器地址和后台密码（明文），只放在自己电脑上，别分享。

电脑要一直开着吗？
------------------
播整曲时需要签名，所以签名器窗口要开着。
想彻底离线听，就把歌「缓存到服务器」（会存到 NAS），之后播放走本地文件，
不再需要签名器。

自动登记（可选）
----------------
不想手抄地址，可以让签名器自己登记：

  start-signer.bat --pair http://192.168.1.120:8027 --password 你的后台密码

安全提醒
--------
- 签名器能看到完整请求头（含 Cookie），只在自己家里/内网用，别做端口转发到公网。
- bdms.node / metasecml.dll 是字节的专有文件，别上传到公开仓库或群里。
