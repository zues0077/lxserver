汽水音乐 签名器（Windows 侧）
=================================

这是什么
--------
让 NAS 上的 LX 能播汽水的**整曲 / 无损**。

签名必须由官方客户端自带的安全组件（bdms.node + metasecml.dll）生成，
所以需要一台装着「汽水音乐」客户端的 Windows 电脑在旁边跑着。

本文件夹已经自带 node.exe，**不需要另外安装 Node.js**，双击即可。


配置方式（推荐：网页配置页）
---------------------------
1. 双击 start-signer.bat
   它会自动打开浏览器到配置页：http://localhost:18080/
   （如果改过端口，就用你设的端口打开）

2. 在网页里填：
   · 端口 / 绑定地址（0.0.0.0 = 允许局域网内 LX 访问）
   · 关联的 LX 服务器：可填**多台**，每行一台的「地址 + 后台密码」
   · 高级里可改 Device ID / 客户端版本号（改了需关掉窗口重开才生效）

3. 点「保存并生效」——**不用重启窗口**：
   · 端口变更 → 签名器热重启监听；
   · 服务器列表变更 → 立即逐台自动登记；删掉某台会通知它清空登记。
   配置落盘到同目录 config.json，下次双击直接生效。


客户端版本（自动识别，不用管）
-----------------------------
签名器启动时会自己认出客户端装在哪、是哪个版本，**不用手工填**。
识别顺序（本机版与 NAS 的 wine 镜像版完全一致）：

  1. <目录>\manifest.json          { version }
  2. <目录>\..\manifest.json       同上
  3. <目录>\..\..\config.json      { latestVersion }
  4. <目录>\version.json           { version }
  5. <目录>\package.json           { version }
  6. 目录名里的 x.y.z

认出哪个就是哪个，会体现在发给汽水的 UA 里。想固定成某个版本，就在配置页「高级」里
手填「客户端版本」并保存（留空 = 每次启动重新识别）。

唯一没法自动识别的是 Build ID（30080000 这类）——客户端文件里没有这个值，只能手填。


找不到客户端 / 想先确认版本
--------------------------
跑 lxserver-soda-signer 仓库根目录的 find-soda-client.bat
（桌面上的「汽水客户端版本识别」也放了一份，用法见同目录的说明 txt）。
它会把本机所有 app.asar.unpacked 列出来、报出各自版本和版本来源，
然后你按它给的目录用 --client 指定即可，例如：

  node signer.js --client "C:\Users\你\AppData\Local\Programs\Soda Music\Packages\3.8.0\app.asar.unpacked"


命令行 / 老用法（兜底）
---------------------
- node signer.js --setup          强制重新填写 LX 服务器（交互式）
- node signer.js --port 18080 --client "C:\...\Soda Music\3.7.0"
- node signer.js --pair http://192.168.1.120:8027 --password xxxx
   （--pair/--password 会作为第一台服务器写入）

提示：双击 start-signer.bat 后窗口里按任意键、或运行「改服务器.bat」，
都会自动打开配置页；想用纯命令行就加 --setup。


换 LX 服务器 / 改地址
---------------------
最省事：双击「改服务器.bat」会直接打开配置页，在网页里改即可。
或直接开 http://localhost:18080/ 自己改，点保存即生效。


多服务器说明
------------
同一台签名器可同时给多台 LX 服务器签名，**互不影响任何汽水账号**——
汽水账号状态存在各台 LX 服务器自己的后台里，签名器本身无状态，
只负责「按收到的请求头生成签名」。所以多服务器设计是安全的。


配置存哪
--------
- 新配置：config.json（端口 / 绑定地址 / 多台服务器 / 设备身份等）
- 旧版 signer-config.json（单 server 字段）会被自动读入并合并，无需手动迁移


出问题看这里
------------
Q: 双击后窗口一闪消失
A: 先看窗口最后几行：
   · 「找不到汽水客户端的 bdms.node」→ 这台电脑没装/没登录过汽水客户端，
     或客户端刚升级；先打开一次客户端让它铺好 app.asar.unpacked，或用
     --client 指定版本目录。
   · 「没找到可用的 Node.js」→ 本文件夹的 node.exe 丢了，从别的电脑拷一份。
   · 什么都没有、窗口纯黑一闪 → 大概率是杀毒软件拦了 node.exe，加白名单再试。

Q: 配置页打不开 / 显示不可达
A: 签名器窗口没开或电脑关机；重新双击 start-signer.bat。
   后台里填的地址末尾不要带斜杠。

Q: 保存后某台服务器「✗ 登记失败」
A: 窗口/页面会写明原因（连接被拒 / 超时 / 密码不对）。
   密码含中文或全角字符时 HTTP 请求头放不下，请改用英文数字部分。


注意
----
config.json / signer-config.json 里存了服务器地址和后台密码（明文），
这个文件夹只放在自己电脑上，别打包分享给别人。

bdms.node / metasecml.dll 是字节的专有文件，别上传到公开仓库或群里。


想彻底不依赖签名器？
--------------------
把歌「缓存到服务器」（存到 NAS），之后播放走本地文件，就不再需要签名器了。
