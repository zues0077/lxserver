汽水音乐 签名器（Windows 侧）
=================================

这是什么
--------
让 NAS 上的 LX 能播汽水的**整曲 / 无损**。

签名必须由官方客户端自带的安全组件生成，所以需要一台装着
「汽水音乐」客户端的 Windows 电脑在旁边跑着。

本文件夹已经自带 node.exe，**不需要另外安装 Node.js**，双击即可。


第一次使用（只有一次）
----------------------
1. 双击 start-signer.bat

   窗口里会问两件事：
     · LX 服务器地址（例：192.168.1.120:8027，不写 http:// 也行）
     · 后台管理员密码

   填完自动登记，并显示「✅ 已自动登记，LX 后台可以直接用了。」

2. 打开 LX 后台 →「平台账号」→ 汽水音乐那一行点「填写 Cookie」
   （要 SVIP 才有版权曲整曲；没有 SVIP 就只能播免费曲和 30 秒试听）

窗口要一直开着 —— 它就是签名服务，关掉就没了。
以后每次开机双击一下即可，不会再问地址密码。


换 LX 服务器 / 改地址
---------------------
**最省事：双击「改服务器.bat」**

它会显示当前填的地址，重新问两项，填完自动登记到新服务器并覆盖配置。
直接回车 = 保持原来的值（所以只改密码也行）。

其它办法：
- 用记事本打开 signer-config.json，改 "server" 那一行（注意逗号引号别删）；
- 删掉 signer-config.json，再双击 start-signer.bat，会重新问。

说明：
- 签名器本身不绑定哪一台 LX。同一台电脑的地址可以同时填给多台 NAS，
  只要它们局域网互通。
- 换了电脑跑签名器 → 地址跟着变；双击一次会自动把新地址重新登记过去。
- 只有 NAS 地址变了才需要手动改（用「改服务器.bat」）。


出问题了看这里
--------------
Q: 双击后窗口一闪就消失了
A: 正常情况下不会。真遇到的话，先看窗口里最后几行字：
   · 如果写着「没找到可用的 Node.js 运行时」→ 本文件夹的 node.exe 丢了，
     从别的电脑拷一份回来（或装 Node.js LTS）。
   · 如果写着「签名器异常退出了」→ 上面几行 [signer] 开头的内容就是原因，
     截图反馈即可。
   · 如果什么都没有、窗口纯黑一闪 → 大概率是杀毒软件拦了 node.exe，
     把它加白名单再试。

Q: 显示「⚠️ 自动登记失败」
A: 窗口里会打印一行地址，形如 http://192.168.1.220:18080。
   复制它，到 LX 后台「平台账号 → 汽水签名器」输入框粘贴，点「保存并测试」。
   失败原因窗口里也写了（连接被拒 / 超时 / 密码不对）。

Q: 后台显示「不可达」
A: 签名器窗口没开，或者电脑关机了。重新双击 start-signer.bat。
   如果开了还是不可达，注意后台里填的地址末尾不要带斜杠。


注意
----
signer-config.json 里存了服务器地址和后台密码（明文），
这个文件夹只放在自己电脑上，别打包分享给别人。

bdms.node / metasecml.dll 是字节的专有文件，别上传到公开仓库或群里。


想彻底不依赖签名器？
--------------------
把歌「缓存到服务器」（存到 NAS），之后播放走本地文件，就不再需要签名器了。
