汽水音乐 签名器（Windows 侧）
=================================

用途
----
让 NAS 上的 LX 能播汽水的**整曲/无损**。签名必须由官方客户端自带的
安全组件生成，所以需要一台装着「汽水音乐」客户端的 Windows 电脑在旁边。

三步搞定
--------
1. 双击 start-signer.bat
   - 电脑上要装过「汽水音乐」官方客户端，并登录过至少一次
   - 需要 Node.js（https://nodejs.org 装 LTS 版即可；
     或把 node.exe 直接放到本文件夹，就不必装）
   - 窗口里会打印一行地址，例如 http://192.168.1.10:18080

2. 打开 LX 后台 → 设置 → 「平台账号」卡片
   → 找到「汽水签名器」输入框 → 粘贴上面那行地址 → 点「保存并测试」
   → 显示「在线，已生效」就好了（这一步只需做一次，会写进配置）

3. 在「汽水音乐」那一行扫码或填 Cookie（需要 SVIP 才有版权曲整曲）

电脑要一直开着吗？
------------------
播整曲时需要签名，所以签名器窗口要开着。
想彻底离线听，就把歌「缓存到服务器」（会存到 NAS），之后播放走本地文件，
不再需要签名器。

自动登记（可选）
----------------
不想手抄地址，可以让签名器自己登记：

  start-signer.bat --pair http://192.168.1.120:8027 --password 你的后台密码

安全提醒
--------
- 签名器能看到完整请求头（含 Cookie），只在自己家里/内网用，别做端口转发到公网。
- bdms.node / metasecml.dll 是字节的专有文件，别上传到公开仓库或群里。
