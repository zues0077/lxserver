汽水签名器 · 配置

本页即签名器本身（http://localhost:18080/）。改完点「保存并生效」即可，无需重启窗口。

签名器监听 本机

LX 后台填的地址就是 http://本机IP:18080
0.0.0.0 = 允许局域网内 LX 访问；127.0.0.1 = 仅本机

关联的 LX 服务器 可多项

一个签名器可同时给多台 LX 服务器签名，互不影响汽水账号。每台填它的后台地址 + 后台密码（admin.password）。
高级：设备身份 / 客户端目录（改了需重启窗口才生效）
以上四项在启动时已加载进签名组件，网页里修改后需关闭再双击 start-signer.bat 才生效。
安全：本页会显示各 LX 后台密码，且签名器能看到完整请求头（含 Cookie）。只在自己家里/可信局域网打开，别做端口转发到公网。
